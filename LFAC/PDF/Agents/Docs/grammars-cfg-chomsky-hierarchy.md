# Formal Grammars, Context-Free Grammars (CFG) & The Chomsky Hierarchy

## 1. Formal Grammar Definition

A **Formal Grammar** is defined as a 4-tuple:
$$G = \langle V_N, V_T, P, S angle$$
Where:
- $V_N$: Finite set of non-terminal symbols (variables / syntactic categories). $V_N \cap V_T = \emptyset$.
- $V_T$: Finite set of terminal symbols (alphabet $\Sigma$).
- $P$: Finite set of production rules of the form $lpha 	o eta$, where $lpha \in (V_N \cup V_T)^* V_N (V_N \cup V_T)^*$ and $eta \in (V_N \cup V_T)^*$.
- $S \in V_N$: Start symbol (distinguished symbol).

---

## 2. The Chomsky Hierarchy

Classifier established by Noam Chomsky (1956/1959) bounding grammar productions and generative capability.

```
       +-------------------------------------------------+
       | Type 0: Unrestricted / RE (Turing Machine)      |
       |  +-------------------------------------------+  |
       |  | Type 1: Context-Sensitive (LBA)         |  |
       |  |  +-------------------------------------+  |  |
       |  |  | Type 2: Context-Free (PDA)          |  |  |
       |  |  |  +-------------------------------+  |  |  |
       |  |  |  | Type 3: Regular (DFA/NFA)     |  |  |  |
       |  |  |  +-------------------------------+  |  |  |
       |  |  +-------------------------------------+  |  |
       |  +-------------------------------------------+  |
       +-------------------------------------------------+
```

| Type | Name | Bounded Production Form ($lpha 	o eta$) | Automaton Equivalence | Example Language |
| :--- | :--- | :--- | :--- | :--- |
| **Type 3** | **Regular** | $A 	o a$, $A 	o aB$, $A 	o \lambda$ ($A, B \in V_N, a \in V_T$) | Finite Automata (DFA / NFA) | $(ab)^* = \{ \lambda, ab, abab, \dots \}$ |
| **Type 2** | **Context-Free (CFG)** | $A 	o \gamma$ ($A \in V_N, \gamma \in (V_N \cup V_T)^*$) | Pushdown Automata (PDA) | $\{a^n b^n \mid n \ge 0\}$ |
| **Type 1** | **Context-Sensitive** | $lpha 	o eta$ with $|lpha| \le |eta|$ (monotonic/non-contracting) | Linearly Bounded Automata (LBA) | $\{a^n b^n c^n \mid n \ge 1\}$ |
| **Type 0** | **Unrestricted** | $lpha 	o eta$ ($lpha 
eq \lambda$, arbitrary contractive rules) | Turing Machine (TM) | Halting / Recursively Enumerable |

## 3. Context-Free Grammars & Derivations

### 3.1 Derivation Relation ($\Rightarrow_G$)
If $A 	o \gamma \in P$, then for any surrounding context $lpha, eta \in (V_N \cup V_T)^*$:
$$lpha A eta \Rightarrow_G lpha \gamma eta$$
- $\Rightarrow_G^+$: Transitive closure (1 or more steps).
- $\Rightarrow_G^*$: Reflexive-transitive closure (0 or more steps).
- **Generated Language $L(G)$:**
  $$L(G) = \{w \in V_T^* \mid S \Rightarrow_G^+ w\}$$

### 3.2 Derivation Trees (Parse Trees)
A **Parse Tree** structurally represents a derivation in a CFG $G$:
1. Root node is labeled with start symbol $S$.
2. Interior nodes are labeled with non-terminals $A \in V_N$.
3. Children of interior node $A$ match production body symbols $X_1 X_2 \dots X_k$ for rule $A 	o X_1 X_2 \dots X_k$.
4. Leaf nodes are labeled with terminal symbols $a \in V_T$ or $\lambda$. Yield of leaves left-to-right forms the derived word.

### 3.3 Normal Forms
- **Chomsky Normal Form (CNF):** Productions are restricted to $A 	o BC$ or $A 	o a$ (where $A, B, C \in V_N, a \in V_T$).
- **Greibach Normal Form (GNF):** Productions are restricted to $A 	o a lpha$ (where $a \in V_T, lpha \in V_N^*$). Directly maps to PDA transitions without $\lambda$-steps.

### 3.4 Equivalence Theorem (Chomsky 1962, Evey 1963)
$$L 	ext{ is generated by a CFG } G \iff L = L_\lambda(M) 	ext{ for some PDA } M$$
